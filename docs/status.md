# Статус на 25 сентября 2026

Задача: начать реализацию по Ongoy_7_Day_Pilot_Plan.md.

## Решения

- Отдельный проект: в доступных GitHub репозиториях и Supabase проектах Oŋoy не найден.
- Реализован первый проверяемый срез: foundation + initial directory CRUD. Не отмечаем всю неделю завершённой.
- Не создавали облачный проект без выбора Supabase организации и подтверждения стоимости. Не меняли существующие проекты.
- Денежные read models возвращают строки, сохраняя точность numeric(16,2). Quantity также передаётся строкой.
- Операции ERP ещё не разрешены; записи в регистры доступны только будущим контролируемым транзакционным командам.

## Проверка кода

Независимый reviewer нашёл две важные ошибки:
1. Возможен перенос directory записи между двумя своими организациями. Исправлено column-level UPDATE grants.
2. Большие суммы теряли точность в JSON number и Number formatter. Исправлено decimal-text read models и форматированием без float.

Регрессионные тесты воспроизвели оба дефекта до исправления и прошли после.
