# Интерфейс: из чего собирать экраны

Правило с 21.10.2026: новый экран или форма собирается из того, что уже есть
ниже. Своё — только если готового нет; тогда оно добавляется сюда же, чтобы
следующий экран взял его, а не нарисовал заново.

Стили — один файл `src/app/globals.css`. Цвета и размеры — токенами из
`:root` в его начале. Тест `tests/ui-tokens.test.mjs` не даёт добавить новый
цвет кодом (`#a34836`), только `var(--danger-ink)`.

## Токены

| Что | Токен |
|-----|-------|
| Текст / второстепенный / бледный | `--ink`, `--muted`, `--ink-soft`, `--faint` |
| Фон страницы / строк / наведения / серая подложка | `--bg`, `--surface-soft`, `--hover`, `--neutral-soft` |
| Рамки: разделители / поля / кнопки | `--line`, `--control-border`, `--button-border` |
| Зелёный бренд и его оттенки | `--green`, `--green-hover`, `--green-soft`, `--green-tint`, `--green-wash`, `--green-border`, `--accent` |
| Успех | `--success-bg`, `--success-ink` |
| Ошибка | `--danger-bg`, `--danger-ink` |
| Подсказка (жёлтая) | `--notice-bg`, `--notice-ink` |
| Предупреждение | `--warning-bg`, `--warning-wash`, `--warning-border`, `--warning-ink`, `--warning-strong` |
| Обводка фокуса | `--focus` |
| Скругления | `--radius-sm` 8px (поля, сообщения), `--radius` 10px (кнопки), `--radius-lg` 12px (плашки) |
| Высота кнопок и полей | `--control-height` 48px |

Нужен новый цвет — добавьте токен в `:root` с комментарием, где он нужен.

## Ширина экрана

В CSS-переменные медиа-запросы не берутся, поэтому договорённость:

- `max-width: 560px` — телефон (основная проверка: всё помещается, кнопки во
  всю ширину, без горизонтальной прокрутки);
- `max-width: 900px` / `min-width: 900px` — планшет / компьютер для форм;
- `min-width: 1000px` — две колонки на экранах результата.

Другие числа в новых правилах не заводить.

## Кнопки

- `.button` — обычная; `.button.primary` — главное действие экрана (одно на
  экран); `.button.danger-outline` — «Отменить запись»; `.button.danger-solid` —
  «Да, удалить» в окне подтверждения; `.text-button` — ссылка-кнопка
  («+ Комментарий»).
- `Submit` — кнопка отправки формы с «Сохраняем…».
- Админка (`/admin`) — свои классы `.adm-*` (список, карточки, вход), только
  там; в магазине не использовать.
- `Turnstile` — проверка «я не робот» перед `Submit` в каждой форме, где
  сервер вызывает `signInWithPassword`, `signUp`, `resend` или
  `resetPasswordForEmail` (ответ — `captchaToken(form)` из `src/lib/captcha.ts`).
- `ConfirmButton` — действие с окном подтверждения (не `confirm()` браузера);
  `DeleteWithUndo` — удаление с «Вернуть».
- В `.simple-operation-actions` кнопки во всю ширину — это для телефона и
  узких форм. На компьютере кнопку не растягивать на всю карточку: обычная
  ширина, справа или под текстом.

## Поля формы

- `label` над полем, поле — `input` / `select` / `textarea` (высота 48px,
  рамка `--control-border`).
- Выбор клиента/поставщика — `PartyPicker`; дата записи —
  `DatePicker variant="field"`; дата в отборах — `DatePicker` с `emptyLabel`;
  количество — `QtyStepper`; комментарий — `NoteField` (свёрнут
  `.text-button`, пока не нужен); пояснение к полю — `InfoTip` вместо строк
  серого текста.
- Выбор из 2–3 вариантов — `.method-pills` с кнопками `.active` и
  `aria-pressed` («В долг / Наличными», «сом / $ / ₽»).
- Вкладки режима — `ModeTabs`.
- За кем останется исправленная продажа/приход — `MakerField` (пилюля
  «Продавец: …» под клиентом, выбрать другого может только владелец).
- Верх формы продажи/прихода — `.sale-sheet-top`: контрагент, дата и
  дополнительное поле в одну строку на компьютере.
- Итог и «Записать» внизу — `.sale-bar` (прилипает к низу экрана).
- Расход (`ExpenseForm`) — компактная форма: чек (миниатюра 56×68, имя файла,
  «+ Добавить фото») и день кнопкой одной строкой `.expense-head`, сообщения
  с чека вплотную под ним `.expense-msgs`; на компьютере (от 900px) подписи
  слева, поля справа, как у оплаты.
- Листы и файлы накладной — `PageViewer`: вкладки `.page-tabs` (миниатюра,
  «№ 15» и сумма, «×»), под ними один крупный просмотр `.page-view` со
  стрелками `.page-view-nav`; на телефоне крупно только фото. Несколько PDF —
  разные накладные: разбивка суммы под полем — `.invoice-files`.
- Категория товара — `CategoryField` (выбор, «+ Новая категория…» и подсказка
  по названию); подсказка, которая ставится одним нажатием, — `.category-chip`
  (`CategoryChip` в списке склада).
- Категории в каталоге клиента — список `.catalog-category-list` (кнопки с
  числом товаров, `.active`, подкатегории с отступом): на компьютере колонкой
  слева, на телефоне раскрывается кнопкой «Категория: …» под поиском.

- Размеры и цвета товара — `VariantPicker` (`components/variant-picker.tsx`):
  ось с названием, справа система размеров `select.variant-system` и
  «+ Свой…» `.variant-add`; размеры — полоса `.variant-strip`, цвета —
  кружки `.variant-swatch` (цвета — `COLOR_SWATCHES` в `lib/product-model.ts`),
  свой цвет — `.variant-chip`. В «Новом товаре» — в рамке `.variant-block`,
  итог «Получится N товаров» — `.variant-result`; количество по сочетаниям —
  `VariantQtyGrid`.
- Наценка под ценами товара — `PriceMarkup` (`.price-markup`, в минус —
  `.loss`).

- Меню кафе (модуль «kitchen») — `MenuStats` и `MenuTable`
  (`components/menu-table.tsx`): одна разметка `.menu-row`, на телефоне
  карточки (заработок под ценой), от 900px — таблица с полоской доли
  продуктов `.menu-bar` (`.high`, `.bad`). Блюдо — `DishForm`
  (`.dish-form`): телефон — колонкой с `.dish-save-bar` внизу над меню,
  компьютер — две колонки, сводка `.dish-summary` с кнопкой справа.
  Пороги доли продуктов — `SHARE_LIMITS` в `lib/dish.ts`.

- `.notice` — жёлтая подсказка; `.notice.success` — зелёное «готово».
- «Письмо отправлено» (`/forgot`) — `.notice.success.mail-sent`: заголовок
  `.mail-sent-title` с галочкой `.mail-sent-check` и шаги `TeachSteps`; под

- `.muted` — второстепенный текст; `.warning` — предупреждение строкой.
- `.tag`, `.tag.green` — короткая метка статуса.
- Пустой раздел нового магазина (`isNewShop` из `lib/new-shop.ts`, первые 30

- «Что умеет Depter» — карточки из `lib/features.ts` на `/features`

- Поддержка в WhatsApp — `supportHref(магазин, где)` из

## Перед тем как отдать экран

1. Телефон 360px: нет горизонтальной прокрутки, главная кнопка видна.
2. Компьютер 1280px: таблицы и формы не сжаты в узкую колонку, кнопки не
   растянуты на всю карточку.
3. Цвета — токены (`npm test` проверит).
