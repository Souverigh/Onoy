# Интерфейс: из чего собирать экраны

Правило с 21.10.2026: новый экран или форма собирается из того, что уже есть
ниже. Своё — только если готового нет; тогда оно добавляется сюда же, чтобы
следующий экран взял его, а не нарисовал заново.

Стили — один файл `src/app/globals.css`. Цвета и размеры — токенами из
`:root` в его начале. Тест `tests/ui-tokens.test.mjs` не даёт добавить новый
цвет кодом (`#a34836`), только `var(--danger-ink)`.

## Токены

| Что | Токен |
|-----|-------|
| Текст / второстепенный / бледный | `--ink`, `--muted`, `--ink-soft`, `--faint` |
| Фон страницы / строк / наведения / серая подложка | `--bg`, `--surface-soft`, `--hover`, `--neutral-soft` |
| Рамки: разделители / поля / кнопки | `--line`, `--control-border`, `--button-border` |
| Зелёный бренд и его оттенки | `--green`, `--green-hover`, `--green-soft`, `--green-tint`, `--green-wash`, `--green-border`, `--accent` |
| Успех | `--success-bg`, `--success-ink` |
| Ошибка | `--danger-bg`, `--danger-ink` |
| Подсказка (жёлтая) | `--notice-bg`, `--notice-ink` |
| Предупреждение | `--warning-bg`, `--warning-wash`, `--warning-border`, `--warning-ink`, `--warning-strong` |
| Обводка фокуса | `--focus` |
| Скругления | `--radius-sm` 8px (поля, сообщения), `--radius` 10px (кнопки), `--radius-lg` 12px (плашки) |
| Высота кнопок и полей | `--control-height` 48px |

Нужен новый цвет — добавьте токен в `:root` с комментарием, где он нужен.

## Ширина экрана

В CSS-переменные медиа-запросы не берутся, поэтому договорённость:

- `max-width: 560px` — телефон (основная проверка: всё помещается, кнопки во
  всю ширину, без горизонтальной прокрутки);
- `max-width: 900px` / `min-width: 900px` — планшет / компьютер для форм;
- `min-width: 1000px` — две колонки на экранах результата.

Другие числа в новых правилах не заводить.

## Страница

- Под вид бизнеса (`lib/business.ts`): разделы меню — модули, названия —
  `navLabel`, кнопки главной — `quickActions`, главная кнопка внизу —
  `mainAction`, свои слова («Закупка продуктов») — `word()`. Новый экран не
  пишет «Товар от поставщика» или «Продажа» в главных кнопках напрямую.
- `.back-link` — «← Назад» над заголовком.
- `.page-heading` — заголовок `h1` и подпись `p.muted`; кнопки справа —
  в `.page-heading-actions`.
- `.panel` — белая карточка с рамкой; заголовок внутри — `.section-title`
  (`h2` слева, счётчик или ссылка справа).
- `.wide-operation-panel` — панель формы на компьютере до 1200px (продажа,
  приход).
- `.details` (`dl` / `dt` / `dd`) — «поле: значение» на странице записи.
- `.table-wrap` + `table` — таблица; на телефоне прокручивается внутри.
- Загрузка — серые макеты из `components/skeleton.tsx` в `loading.tsx`.
- Страницы для клиентов без входа (`/c/…`, `/catalog/…`) — `main.client-page`
  без бокового меню; каталог — `CatalogView` (поиск, «Мой список», «Отправить
  заказ» окном `.catalog-order`); заказы клиента со статусом — `ClientOrders`
  (в каталоге за кнопкой `.catalog-my-orders`, на странице клиента — панелью).
- Продажи и приход (`RecordsPage`, макет 28.10.2026) — одна белая панель
  `.record-panel`: вкладки `.tabs.record-tabs` со счётчиком
  `.record-tab-count` (`.warn` — черновики), отборы `JournalBar`, строка
  `.record-drafts-line`, полоса итога `.record-totals`, таблица
  `.record-table` (сумма `.record-sum` справа, время `.record-time` под датой)
  и на телефоне карточки `.record-cards` / `.record-card`; внизу
  `.record-pages` («Показано 1–15 из N»). Метка оплаты — `.pay-tag`
  (`.debt` — в долг, `.cash` — наличными, `.off` — отменена); «Оплачено» и
  «Частично» у продажи не бывает — оплата гасит долг клиента, а не продажу.
  Действия записи — `details.more-menu.record-menu` с кнопкой «⋯»
  `.record-menu-toggle`; опасный пункт — `a.danger-link`.
- Заказы из каталога в кабинете — таблицей, как продажи (`.op-table` +
  `.op-list-mobile`, строка `.record-row` ведёт на заказ); на странице заказа
  «На кого продажа» — `.order-customer`: варианты списком в одной рамке
  `.order-choice-list`, строка `.order-choice` (радиокнопка или значок
  `.order-choice-mark`, имя и телефон `.order-choice-main` слева, долг
  `.order-choice-side` справа; выбранная — зелёная). Под списком главная
  кнопка и `.text-button` в одну строку (`.order-actions`).
- Прокат (модуль `rental`) — список `ul.rental-list` из строк `.op-list-item`
  (вещи и залог — `.op-list-meta` во всю ширину, «Вернул» и WhatsApp —
  `.rental-row-actions`, просроченная — `.rental-late`); «Выдать» на телефоне —
  внизу (`.directory-bottom-actions`). Форма — `RentalForm`: вещи карточками
  `.rental-catalog` с кнопками размеров `.rental-size` (выбрано — `.picked`),
  выбранные с ценой за сутки — `.rental-picked` (список — только по поиску);
  «Дней» и «Сумма» — одной строкой `.rental-sum-row`; «Оплатил сейчас» —
  меньше суммы = частичная оплата; залог — пилюли с переносом
  `.method-pills.rental-pills`; залог деньгами и комментарий — свёрнуты
  `.note-toggle`; итог, «Оплатил / В долг» и «Выдать» — `.sale-bar`. Возврат —
  `RentalReturn` (доплата строкой и пилюлями). Расчёты — `lib/rentals.ts`.
- Товар с размерами и цветами — `ModelForm` (`/stock/model/…`): выбор
  нескольких значений — `AxisPicker`, поле-кнопка `.axis-picker-button` с
  выбранным через запятую, по нажатию — `details.more-menu` с группами
  галочек (`label.axis-option`, «Выбрать все»), «Свой вариант» и «Готово»;
  на телефоне список раскрывается в форме, не поверх. Форма — блоками
  `.model-section` с заголовком `.model-section-title` («1. Модель»…),
  что получится — метки в `.model-preview`; количество при создании —
  только за переключателем «Товар уже есть в магазине» (так же в
  `ProductForm` — свёрнутым `details.more-fields`). Остатки —
  `table.variant-grid` (число `.variant-cell`, новое — поле `.variant-qty`).
- Размеры одной модели везде собираются в одну запись (`groupByModel`,
  порядок размеров — `sortVariants` из `lib/product-model.ts`): на складе —
  строка модели с метками `.stock-variant` (остаток, мало — `.low`); в
  поиске товара продажи — `.product-model-result` с кнопками
  `.product-size`; в каталоге клиента — карточка `.catalog-model` с
  кнопками `.catalog-size` и строками `.catalog-size-row` со счётчиком.
- Выбор строкой внутри `form` — селектор `form label.<класс>`: общее правило
  `form label` (колонка, отступ снизу 18px) и полей (`width: 100%`,
  `min-height: 48px`) иначе растягивает строку и рисует огромный кружок.

## Кнопки

- `.button` — обычная; `.button.primary` — главное действие экрана (одно на
  экран); `.button.danger-outline` — «Отменить запись»; `.button.danger-solid` —
  «Да, удалить» в окне подтверждения; `.text-button` — ссылка-кнопка
  («+ Комментарий»).
- `Submit` — кнопка отправки формы с «Сохраняем…».
- `ConfirmButton` — действие с окном подтверждения (не `confirm()` браузера);
  `DeleteWithUndo` — удаление с «Вернуть».
- В `.simple-operation-actions` кнопки во всю ширину — это для телефона и
  узких форм. На компьютере кнопку не растягивать на всю карточку: обычная
  ширина, справа или под текстом.

## Поля формы

- `label` над полем, поле — `input` / `select` / `textarea` (высота 48px,
  рамка `--control-border`).
- Выбор клиента/поставщика — `PartyPicker`; дата записи —
  `DatePicker variant="field"`; дата в отборах — `DatePicker` с `emptyLabel`;
  количество — `QtyStepper`; комментарий — `NoteField` (свёрнут
  `.text-button`, пока не нужен); пояснение к полю — `InfoTip` вместо строк
  серого текста.
- Выбор из 2–3 вариантов — `.method-pills` с кнопками `.active` и
  `aria-pressed` («В долг / Наличными», «сом / $ / ₽»).
- Вкладки режима — `ModeTabs`.
- За кем останется исправленная продажа/приход — `MakerField` (пилюля
  «Продавец: …» под клиентом, выбрать другого может только владелец).
- Верх формы продажи/прихода — `.sale-sheet-top`: контрагент, дата и
  дополнительное поле в одну строку на компьютере.
- Итог и «Записать» внизу — `.sale-bar` (прилипает к низу экрана).
- Расход (`ExpenseForm`) — компактная форма: чек (миниатюра 56×68, имя файла,
  «+ Добавить фото») и день кнопкой одной строкой `.expense-head`, сообщения
  с чека вплотную под ним `.expense-msgs`; на компьютере (от 900px) подписи
  слева, поля справа, как у оплаты.
- Листы и файлы накладной — `PageViewer`: вкладки `.page-tabs` (миниатюра,
  «№ 15» и сумма, «×»), под ними один крупный просмотр `.page-view` со
  стрелками `.page-view-nav`; на телефоне крупно только фото. Несколько PDF —
  разные накладные: разбивка суммы под полем — `.invoice-files`.
- Категория товара — `CategoryField` (выбор, «+ Новая категория…» и подсказка
  по названию); подсказка, которая ставится одним нажатием, — `.category-chip`
  (`CategoryChip` в списке склада).
- Категории в каталоге клиента — список `.catalog-category-list` (кнопки с
  числом товаров, `.active`, подкатегории с отступом): на компьютере колонкой
  слева, на телефоне раскрывается кнопкой «Категория: …» под поиском.

## Сообщения

- `.notice` — жёлтая подсказка; `.notice.success` — зелёное «готово».
- `.form-error` (`role="alert"`) — ошибка; текст — что случилось и что
  сделать, без технических слов.
- `.muted` — второстепенный текст; `.warning` — предупреждение строкой.
- `.tag`, `.tag.green` — короткая метка статуса.

## Перед тем как отдать экран

1. Телефон 360px: нет горизонтальной прокрутки, главная кнопка видна.
2. Компьютер 1280px: таблицы и формы не сжаты в узкую колонку, кнопки не
   растянуты на всю карточку.
3. Цвета — токены (`npm test` проверит).
